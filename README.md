## 06 — Engineering principles

- **Keep changes reviewable.** Small commits are easier to understand, debug, and revert.
- **Choose proven tools by default.** Add complexity only when there's a clear reason.
- **Record the reasoning.** Document non-obvious trade-offs in code or commit messages.
- **Prefer correctness to scope.** A smaller, dependable system is better than a larger, fragile one.
